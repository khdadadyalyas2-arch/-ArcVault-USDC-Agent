# ArcVault USDC Agent 🏦
> Autonomous USDC Micro-Treasury & Policy Safe for AI Agents.

This project enables AI agents to handle USDC payments within predefined legal and financial guardrails, ensuring autonomous but safe treasury management.

## Features
- **Programmable Escrow:** Automated fund release based on agent logic.
- **Spending Policies:** Hard limits on daily and per-transaction volume.
- **On-chain Traceability:** Full audit logs for every autonomous transfer.
